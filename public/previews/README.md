# Previews

Compose sources for the personal-project card images in
`public/images/`. Each `compose-*.html` renders one card image: it places
an original screenshot (changed only by crop and resize), adds the
official product logo and a small honest label, and is screenshotted at
1188x744 to produce the final PNG.

Sources, provenance, license notes, and regeneration steps are documented
in `docs/media-sources.md`.
